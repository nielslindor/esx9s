# Drift Keeping

The current product slice is a terminal control plane for standalone ESXi fleets.

Allowed now:

- Mock TUI foundation
- Multi-host inventory model
- Config loader
- Audit log
- Confirmation guard
- Read-only ESXi connection probing

Not now:

- Kubernetes
- Web UI
- AI remediation
- vCenter clone scope
- Distributed switches
- HA/vMotion/DRS replacement work

When a good idea appears, park it in an issue or a later roadmap phase, then return to the current acceptance criteria.
